## Readora-Chronicles
Readora Chronicles is a modern online reading and story-discovery platform inspired by Wattpad. It allows readers to discover stories by genre, explore popular content and authors, and experience dedicated story pages with immersive visuals and story-focused content.
## Technologies
HTML • CSS • Tailwind CSS

## Features
*  Easy story discovery and exploration
*  Browse stories by genre
*  Five genres: Thriller, Fantasy, Romance, Humor, and Anime
*  Popular and trending stories
*  Dedicated Authors page
*  Discover featured authors and their inspirations
*  Dedicated pages for individual stories
*  Story-related visuals and immersive layouts
*  Quotes, teasers, and story highlights
*  Clear **Start Reading** experience
*  Clean and user-friendly interface
*  Modern design using Tailwind CSS
*  Simple and organized navigation
